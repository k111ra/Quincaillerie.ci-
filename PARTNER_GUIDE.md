## 🚀 COMMENT COMMENCER?

### Étape 1: Inscription
1. Cliquez sur **"Devenez Partenaire"** dans le header du site
2. Remplissez le formulaire avec vos informations:
   - **Informations personnelles**: Nom, Email, Mot de passe
   - **Informations entreprise**: Nom, Téléphone, WhatsApp (optionnel), Site web, Description
3. Cliquez sur **"Créer mon compte partenaire"**

### Étape 2: Attendre l'approbation
- ⏳ Notre équipe examine votre profil
- 📧 Vous recevrez une confirmation par email quand votre compte sera approuvé
- ✅ Une fois approuvé, vous pourrez:
  - Publier vos offres
  - Recevoir des demandes de clients
  - Gérer vos réponses

## ❓ FAQ

**Q: Combien de temps pour l'approbation?**
A: Généralement 24-48 heures. Vous recevrez un email de confirmation.

**Q: Puis-je modifier mes informations après inscription?**
A: Oui, après approbation. Vous aurez un profil à modifier dans votre tableau de bord.

**Q: Combien ça coûte?**
A: L'inscription est gratuite. Les tarifs seront communiqués prochainement.

**Q: Quels types d'offres puis-je publier?**
A: Produits, services, ou solutions dans le domaine de la quincaillerie et secteurs connexes.

**Q: Comment recevoir les notifications?**
A: Par email automatiquement. Vous pouvez aussi activer WhatsApp lors de l'inscription.
